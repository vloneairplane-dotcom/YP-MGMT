## ✨ امکانات

### 🤖 ربات تلگرام
| بخش | توضیح |
|---|---|
| 🎯 **نقش‌ها** | ثبت نقش هر عضو: آرتیست 🎤 / پرودیوسر 🎛️ / دیزاینر 🎨 / منیجر 🧑‍💼 / ادمین 👑 |
| 📁 **پروژه‌ها** | ساخت پروژه با نوع (بیت، دمو، سینگل، کاور، موزیک‌ویدیو…)، توضیح و **ددلاین مشخص** |
| 📊 **وضعیت پروژه** | جریان کاری: ایده 💡 → دمو 🎤 → ضبط 🎙️ → میکس 🎛️ → مستر 🎚️ → ریلیز 🚀 → تمام ✅ |
| 🧩 **تسک‌ها** | تسک اختصاصی برای هر نفر با اولویت (کم 🟢 تا فوری 🔴) و ددلاین + اعلان دی‌ام به مسئول تسک |
| 💡 **ایده بگیر** | موتور ایده‌یاب خودکار: کانسپت آهنگ، بیت، تم متن، کاور/ویژوال، استراتژی ریلیز، کالب — به‌علاوه **بریف کامل پروژه** |
| ⏰ **یادآور ددلاین** | اعلان خودکار ۲ روز قبل / روز ددلاین / بعد از گذشت — برای پروژه و تسک |
| 👥 **حالت گروه** | افزودن ربات به گروه کاری + دستورهای `/start` `/team` `/tasks` `/deadline` `/idea` `/whoami` |
| ⚙️ **پنل ادمین** | آمار کامل، مدیریت نقش اعضا، پروژه‌های آرشیو، اعلان همگانی |

### 💎 داشبورد شیشه‌ای (وب)
- استایل **گلس‌مورفیسم** با افکت‌های نئونی بنفش/فیروزه‌ای/صورتی
- نمایش زنده‌ی پروژه‌ها، پیشرفت تسک‌ها، تیم، ایده‌ها و فعالیت‌ها
- نزدیک‌ترین ددلاین + شمارش معکوس
- راست‌به‌چپ کامل با فونت وزیرمتن

## 🚀 راه‌اندازی

### ۱) پیش‌نیاز
- Python 3.10+

### ۲) نصب پکیج‌ها
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۳) ساخت ربات تلگرام
1. در تلگرام [@BotFather](https://t.me/BotFather) را باز کن
2. `/newbot` → اسم ربات (مثلاً `Ye Pesare MGMT`) → یوزرنیم (مثلاً `ye_pesare_mgmt_bot`)
3. توکن ربات کپی کن

### ۴) تنظیم متغیرها
```bash
cp .env.example .env
```
سپس داخل `.env`:
```env
BOT_TOKEN=توکن_از_бот_فادر
ADMIN_IDS=آیدی_عددی_شما
GROUP_CHAT_ID=آیدی_عددی_گروه_کاری   # اختیاری
```
> 💡 آیدی عددی‌ات رو از [@userinfobot](https://t.me/userinfobot) بگیر.
> برای آیدی گروه: ربات [@RawDataBot](https://t.me/RawDataBot) رو توی گروه اد کن و `chat.id` رو بردار.

### ۵) اجرا
```bash
python3 run.py
```
- 💎 داشبورد شیشه‌ای → `http://localhost:8000`
- 🤖 ربات تلگرام → آنلاین و آماده‌ی استفاده

## 👥 راه‌اندازی در گروه کاری
1. ربات رو به گروه اضافه کن (ادمین گروهش کن تا پیام بتونه بفرسته)
2. هر عضو `/start` رو بزنه و نقش خودش رو انتخاب کنه
3. منیجر/ادمین می‌تونه از «➕ پروژه جدید» پروژه تعریف کنه و به هر نفر تسک بده
4. ربات یادآوری ددلاین‌ها رو خودکار براشون می‌فرسته

## 📱 دستورهای سریع
| دستور | کار |
|---|---|
| `/start` | منوی اصلی / ثبت نقش |
| `/team` | لیست تیم و نقش‌ها |
| `/tasks` | تسک‌های من |
| `/deadline` | ددلاین‌های ۷ روز آینده |
| `/idea` | یه ایده‌ی سریع |
| `/whoami` | نقش من |
| `/help` | راهنما |
| `/backup` | (مدیر) ارسال فایل دیتابیس در دی‌ام 💾 |
| `/restore` | (مدیر) بازگرداندن همون فایل بکاپ داخل چت — بدون دسترسی به سرور 📦 |
| `/wipe` | (مدیر) خالی‌کردن بورد با تأییدیه 🧹 |
| `/reset_all` | (ادمین اصلی) ریست کارخانه‌ای: همه‌چی + اعضا و نقش‌ها 🧨 |

## 🔐 قفل گروهی (Group Lock)
با تنظیم `GROUP_CHAT_ID` در env، ربات **فقط و فقط** توی همون گروه کاری شما حرف می‌زنه:
- 👤 **پیوی/دی‌ام برای همه قفله** — غریبه‌ها پیام قفل می‌گیرن و بعدش ربات کاملاً ساکته
- 👑 ادمین‌های `ADMIN_IDS` برای ابزارها (`/backup`, `/restore`, پنل) مسیر دی‌ام رو باز دارن
-  گروه‌های دیگه: ربات در آن‌ها هیچ‌وقت پاسخ نمی‌ده (ساکتِ ساکت)
- 🧭 پیدا کردن آیدی گروه: بات رو اد کن، پیامی بفرست، در لاگ Render خط
  `🔒 blocked chat id=-100…` رو ببین و همون عدد رو در `GROUP_CHAT_ID` بذار

> 💡 **چرخه‌ی حیات روی هاست رایگان:** هر دیپلوی دیتابیس رو صفر می‌کنه ←
> قبل از آپدیت `/backup` بزن، بعد از دیپلوی `/restore` کن و فایل `.db` رو بفرست.
> ربات اول سلامت فایل رو چک می‌کنه (integrity + جداول)، نسخه‌ی قبلی رو هم
> کنار فایل `data/…db.pre-restore` نگه می‌داره. بازگردانی **بدون ریستارت** اعمال می‌شه.

## 🗂 ساختار پروژه
```
YP-MGMT/
├── run.py               # اجرای هم‌زمان ربات + داشبورد
├── bot/
│   ├── main.py          # سیم‌کشی هندلرها و یادآورها
│   ├── config.py        # نقش‌ها، وضعیت‌ها، تنظیمات
│   ├── database.py      # SQLite + داده‌ی دمو
│   ├── texts.py         # متن‌های فارسی
│   ├── keyboards.py     # کیبوردهای اینلاین
│   ├── handlers/        # منو، نقش، پروژه، تسک، ایده، ادمین، گروه
│   └── services/        # موتور ایده + یادآور ددلاین
└── dashboard/
    ├── app.py           # FastAPI + API داشبورد
    ├── templates/       # پنل شیشه‌ای
    └── static/          # CSS/JS
```

## ⚙️ نکات فنی
- دیتابیس: SQLite در `data/yp_mgmt.db` (خودکار ساخته می‌شود)
- **بورد از صفر خالی است** ✅ — داده‌ی دمو فقط با `DEMO_SEED=1` در `.env` ساخته می‌شود
- از پنل ادمین ربات: «💾 بکاپ دیتابیس» و «🧹 پاک‌سازی بورد» (یا دستور `/backup` و `/wipe`)
- متن‌ها با HTML رندر می‌شن؛ نام/توضیحات کاربر به‌صورت امن escape می‌شه
- یادآور ددلاین هر ۳۰ دقیقه چک می‌شود
- اگر سرور به `api.telegram.org` دسترسی نداره (مثلاً سرور داخل ایران): در `.env` مقدار `TELEGRAM_PROXY` رو مثل `socks5://user:pass@host:port` تنظیم کن

## 💰 اجرای کاملاً رایگان

> ربات تلگرام باید **همیشه روشن** باشه (پروسه‌ی دائمی). گزینه‌های واقعاً رایگان:

### 🥇 گزینه ۱ — Oracle Cloud «Always Free» (بهترین، همیشه‌رایگان)
یه سرور مجازی واقعی ۲۴/۷ — بدون هزینه‌ی ماهیانه (ثبت‌نام با کارت بین‌المللی فقط برای تأیید هویت؛ هیچ شارژی نمی‌شه).

۱) توی [oracle.com/cloud/free](https://www.oracle.com/cloud/free/) ثبت‌نام کن
۲) یک **Compute Instance** بساز:
   - Image: **Ubuntu 24.04**
   - Shape: **VM.Standard.A1.Flex** با **2 OCPU / 12 GB RAM** (همون سهمیه‌ی رایگان)
   - اگر پیام `Out of host capacity` دادی، ریجن/AD دیگه رو امتحان کن یا از **VM.Standard.E2.1.Micro** (AMD) استفاده کن
۳) توی **Security List** فقط پورت `8000` رو برای داشبورد باز کن (ربات اصلاً پورت باز نمی‌خواد — خودش Polling می‌زنه)
۴) با SSH وصل شو:
```bash
sudo apt update && sudo apt install -y python3-venv git
git clone https://github.com/vloneairplane-dotcom/YP-MGMT.git /opt/YP-MGMT
cd /opt/YP-MGMT
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env        # توکن ربات + آیدی ادمین
```
۵) سرویس رو دائمی کن (با هر ری‌استارت سرور بالا میاد):
```bash
sudo cp deploy/yp-mgmt.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now yp-mgmt
sudo systemctl status yp-mgmt            # باید active (running) باشه
```
✅ تموم! ربات آنلاینه → داشبورد هم `http://IP-سرور:8000`

> ⚠️ **ترفند مهم:** اوراکل ماشین‌های بیکار (کمتر از ۲۰٪ مصرف برای ۷ روز) رو جمع می‌کنه.
> راه حل رایگان و قطعی: اکانت رو به **Pay As You Go** ارتقا بده (بدون هزینه تا سقف رایگان، هیچ شارژی نمیشه)
> ولی دیگه از لیست جمع‌کردن ماشین‌های بیکار معاف می‌شی. (پولینگ ربات + یادآورها هم خودش فعالیت ایجاد می‌کنه)

### 🥈 گزینه ۲ — Render (بدون کارت، از GitHub)
۱) توی [render.com](https://render.com) با گیت‌هاب لاگین کن → **New → Web Service** → ریپو `YP-MGMT`
۲) Docker رو انتخاب کن (خودکار `Dockerfile` رو می‌بینه)
۳) توی **Environment** متغیرهای `.env` رو اضافه کن (`BOT_TOKEN`, `ADMIN_IDS`)
۴) پلن **Free** رو بزن → Deploy
۵) 🎯 ترفند بیدار نگه‌داشتن: سرویس رایگان بعد از ۱۵ دقیقه بی‌کاری می‌خوابه.
   توی [UptimeRobot](https://uptimerobot.com) (رایگان) یک **HTTP Monitor** بساز که هر ۵ دقیقه
   آدرس داشبوردت رو پینگ کنه → سرویس ۲۴/۷ بیدار می‌مونه. (بدون پینگ هم ربات کار می‌کنه ولی با تأخیر)

### 🥉 گزینه ۳ — گوشی/کامپیوتر قدیمی + Termux (بدون سرور، بدون کارت)
۱) [Termux](https://f-droid.org/packages/com.termux/) رو از F-Droid نصب کن
```bash
pkg install python git
git clone https://github.com/vloneairplane-dotcom/YP-MGMT.git
cd YP-MGMT && pip install -r requirements.txt
cp .env.example .env && nano .env
termux-wake-lock          # گوشی نخوابه
python3 run.py
```
۲) گوشی رو به شارژر و وای‌فای وصل نگه‌دار — همین! 📱
