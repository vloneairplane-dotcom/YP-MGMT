## ✨ امکانات

### 🤖 ربات تلگرام
| بخش | توضیح |
|---|---|
| 🎯 **نقش‌ها** | ثبت نقش هر عضو: آرتیست 🎤 / پرودیوسر 🎛️ / دیزاینر 🎨 / منیجر 🧑‍💼 / ادمین 👑 |
| 📁 **پروژه‌ها** | ساخت پروژه با نوع (بیت، دمو، سینگل، کاور، موزیک‌ویدیو…)، توضیح و **ددلاین مشخص** |
| 📊 **وضعیت پروژه** | جریان کاری: ایده 💡 → دمو 🎤 → ضبط 🎙️ → میکس 🎛️ → مستر 🎚️ → ریلیز 🚀 → تمام ✅ |
| 🧩 **تسک‌ها** | تسک اختصاصی برای هر نفر با اولویت (کم 🟢 تا فوری 🔴) و ددلاین + اعلان دی‌ام به مسئول تسک |
| 💡 **ایده بگیر** | موتور ایده‌یاب خودکار: کانسپت آهنگ، بیت، تم متن، کاور/ویژوال، استراتژی ریلیز، کالب — به‌علاوه **بریف کامل پروژه** |
| ⏰ **یادآور ددلاین** | اعلان خودکار ۲ روز قبل / روز ددلاین / بعد از گذشت — برای پروژه و تسک |
| 👥 **حالت گروه** | افزودن ربات به گروه کاری + دستورهای `/start` `/team` `/tasks` `/deadline` `/idea` `/whoami` |
| ⚙️ **پنل ادمین** | آمار کامل، مدیریت نقش اعضا، پروژه‌های آرشیو، اعلان همگانی |

### 💎 داشبورد شیشه‌ای (وب)
- استایل **گلس‌مورفیسم** با افکت‌های نئونی بنفش/فیروزه‌ای/صورتی
- نمایش زنده‌ی پروژه‌ها، پیشرفت تسک‌ها، تیم، ایده‌ها و فعالیت‌ها
- نزدیک‌ترین ددلاین + شمارش معکوس
- راست‌به‌چپ کامل با فونت وزیرمتن

## 🚀 راه‌اندازی

### ۱) پیش‌نیاز
- Python 3.10+

### ۲) نصب پکیج‌ها
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۳) ساخت ربات تلگرام
1. در تلگرام [@BotFather](https://t.me/BotFather) را باز کن
2. `/newbot` → اسم ربات (مثلاً `Ye Pesare MGMT`) → یوزرنیم (مثلاً `ye_pesare_mgmt_bot`)
3. توکن ربات کپی کن

### ۴) تنظیم متغیرها
```bash
cp .env.example .env
```
سپس داخل `.env`:
```env
BOT_TOKEN=توکن_از_бот_فادر
ADMIN_IDS=آیدی_عددی_شما
GROUP_CHAT_ID=آیدی_عددی_گروه_کاری   # اختیاری
```
> 💡 آیدی عددی‌ات رو از [@userinfobot](https://t.me/userinfobot) بگیر.
> برای آیدی گروه: ربات [@RawDataBot](https://t.me/RawDataBot) رو توی گروه اد کن و `chat.id` رو بردار.

### ۵) اجرا
```bash
python3 run.py
```
- 💎 داشبورد شیشه‌ای → `http://localhost:8000`
- 🤖 ربات تلگرام → آنلاین و آماده‌ی استفاده

## 👥 راه‌اندازی در گروه کاری
1. ربات رو به گروه اضافه کن (ادمین گروهش کن تا پیام بتونه بفرسته)
2. هر عضو `/start` رو بزنه و نقش خودش رو انتخاب کنه
3. منیجر/ادمین می‌تونه از «➕ پروژه جدید» پروژه تعریف کنه و به هر نفر تسک بده
4. ربات یادآوری ددلاین‌ها رو خودکار براشون می‌فرسته

## 📱 دستورهای سریع
| دستور | کار |
|---|---|
| `/start` | منوی اصلی / ثبت نقش |
| `/team` | لیست تیم و نقش‌ها |
| `/tasks` | تسک‌های من |
| `/deadline` | ددلاین‌های ۷ روز آینده |
| `/idea` | یه ایده‌ی سریع |
| `/whoami` | نقش من |
| `/help` | راهنما |

## 🗂 ساختار پروژه
```
YP-MGMT/
├── run.py               # اجرای هم‌زمان ربات + داشبورد
├── bot/
│   ├── main.py          # سیم‌کشی هندلرها و یادآورها
│   ├── config.py        # نقش‌ها، وضعیت‌ها، تنظیمات
│   ├── database.py      # SQLite + داده‌ی دمو
│   ├── texts.py         # متن‌های فارسی
│   ├── keyboards.py     # کیبوردهای اینلاین
│   ├── handlers/        # منو، نقش، پروژه، تسک، ایده، ادمین، گروه
│   └── services/        # موتور ایده + یادآور ددلاین
└── dashboard/
    ├── app.py           # FastAPI + API داشبورد
    ├── templates/       # پنل شیشه‌ای
    └── static/          # CSS/JS
```

## ⚙️ نکات فنی

- یادآور ددلاین هر ۳۰ دقیقه چک می‌شود
- برای استقرار روی سرور: `python3 run.py` داخل `tmux`/`systemd`
